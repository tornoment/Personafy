# Personafy для iPhone

**Скачать:** [Personafy.ipa](https://github.com/tornoment/personafy/raw/ios/Personafy.ipa) · номер сборки и дата — в `build.txt`.

Файл не подписан: подписывает его Sideloadly вашим Apple ID прямо при установке. Бесплатный Apple ID даёт подпись на 7 дней — потом приложение перестаёт открываться, и его нужно поставить заново тем же способом (избранное, очередь и скачанные треки при этом сохраняются).

## Установка с компьютера на Windows

1. Поставьте **iTunes с сайта Apple** (не из Microsoft Store!) — от него нужны драйверы для iPhone: https://www.apple.com/itunes/download/win64
2. Поставьте **Sideloadly**: https://sideloadly.io
3. Подключите iPhone кабелем, на телефоне нажмите «Доверять этому компьютеру».
4. В Sideloadly: выберите телефон, впишите свой Apple ID, перетащите `Personafy.ipa` в окно и нажмите **Start**. Введите пароль Apple ID (и код, если придёт).
5. На iPhone один раз включите **Режим разработчика**: Настройки → Конфиденциальность и безопасность → Режим разработчика → вкл. (телефон перезагрузится).
6. Разрешите свой Apple ID: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

## Раз в 7 дней

Повторите шаг 4 с тем же файлом (или с новой сборкой отсюда). Приложение обновится поверх, данные останутся.
