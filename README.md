# Personafy для Android

**Скачать:** [Personafy.apk](https://github.com/tornoment/personafy/raw/android/Personafy.apk) · номер сборки и дата — в `build.txt`.

Ничего подписывать и переустанавливать каждую неделю не нужно (это только на iPhone): поставили один раз — и пользуетесь. Новая версия ставится поверх старой, избранное, очередь и скачанные треки сохраняются.

## Установка прямо на телефоне

1. Откройте ссылку «Скачать» выше в браузере телефона (Chrome) и скачайте `Personafy.apk`.
2. Нажмите на скачанный файл (в шторке уведомлений или в «Файлах» → «Загрузки»).
3. Android спросит разрешение устанавливать приложения из этого источника: «Настройки» → включить «Разрешить из этого источника» → назад.
4. Нажмите «Установить». Если появится Google Play Защита («Приложение не проверено») — «Подробнее» → «Всё равно установить».
5. Значок Personafy (цилиндр) появится среди приложений.

## Обновление

Скачайте новый `Personafy.apk` по той же ссылке и установите поверх — Android покажет «Обновить».

## Как работает на Android

- Музыка играет в фоне и с выключенным экраном; плеер с обложкой и кнопками — в шторке уведомлений и на экране блокировки. Работают кнопки наушников, Bluetooth-гарнитуры и часов.
- Если выдернуть наушники, музыка встаёт на паузу.
- Кнопка/жест «Назад» закрывает настройки и очередь, возвращает из «Сейчас играет», а на главной сворачивает приложение — музыка не останавливается. Чтобы остановить совсем — пауза, или смахнуть Personafy из списка недавних приложений.
- Громкость — кнопками телефона.
