# Как устроен Personafy

Personafy — музыкальный плеер для Windows, iPhone и Android в стиле Persona 5 с темами Persona 3 Reload и Metaphor: ReFantazio. Версия для Windows написана на Electron, телефонные версии — тот же интерфейс в обёртке Capacitor. Интерфейс — чистый JavaScript без фреймворков (`app/src`).

До версии 1.5.0 плеер назывался Phantom Player, и часть внутренних имён осталась прежней: данные пользователя (избранное, очередь, скачанные треки, тексты, обложки, замеры громкости) лежат в `%AppData%\Phantom Player`, appId — `com.phantomplayer.app`, внутренний протокол — `phantom://`, ключи хранилища — `phantom-player.*`. Поэтому установщик обновляет старую установку поверх, ничего не теряя, а старые ярлыки «Phantom Player» переименовываются в «Personafy».

## Музыка

- Треки хранятся на Google Диске в общей папке: https://drive.google.com/drive/folders/1kPXbDJDwlhdNe662bjNLk8xAW6gdw98z
- Внутри — по папке на альбом (`p5`, `p5r`, `p3r`, `singles`, `Persona 4 Golden`, `Persona 3 Reload - Episode Aigis`, `Persona 4 Dancing All Night`). В каждой — mp3 с именами вида `017 - Last Surprise.mp3` и обложка `cover.jpg`.
- Плеер играет треки прямо с Диска. Диск отдаёт файлы только страницам Google, поэтому окно плеера к нему не обращается: трек скачивает основной процесс и передаёт в окно через `phantom://`.
- Для офлайна треки скачиваются в «Библиотеке» кнопкой СКАЧАТЬ.

### Как добавить музыку

- **Трек:** положить mp3 в папку альбома с номером в начале имени (`61 - Burn My Dread -Reload-.mp3`). Доступ к папке — «все, у кого есть ссылка».
- **Альбом:** создать рядом новую папку с треками и `cover.jpg`. Имя папки становится названием альбома в плеере.
- При запуске плеер проверяет Диск и сообщает о новых треках.
- Для новых альбомов плеер сам узнаёт длительность, исполнителя и год: в фоне, по три файла сразу, читает с Диска только начало каждого mp3 (заголовок и теги). Пока данные не прочитаны, вместо длительности показывается «—:—». Узнанное сохраняется в `trackmeta.json` в папке данных и второй раз не читается.
- Обложки альбомов с Диска сохраняются в папку `covers` в данных плеера.

### Заметки об альбомах

- **Persona 4 Golden** — 63 трека, рип музыки из игры (файлы BGM 001–069). Названия — по таблице BGM на вики Amicitia: https://amicitia.miraheze.org/wiki/Persona_4_Golden/SND/BGM. Порядок — по игровым номерам; некоторые треки длинные, потому что в игре они зациклены. Четыре трека без названия (BGM 045, 062, 065, 067) стоят в конце как «Без названия (BGM …)». Короткие фрагменты и заставки (BGM 060, 063, 064, 066, 068, 069) не включены. Обложка нарисована заново, без логотипов.
- **Persona 3 Reload - Episode Aigis** — 21 трек, официальный альбом «Persona 3 Reload: Episode Aigis Original Soundtrack» (2024). Двоеточия в названиях заменены на « -» (Windows их не разрешает), «3/31» записан как «3-31».
- **Persona 4 Dancing All Night** — 79 треков, официальный альбом «Persona 4: Dancing All Night - The Complete Soundtrack» (2015). Номера как на диске: 01–72 и 75–81; треки 73 и 74 — повторы 13 и 14 (проверено по отпечаткам звука). Кавычки и «?» из названий убраны.

## Тексты песен

- Берутся из открытой базы [LRCLIB](https://lrclib.net) во время прослушивания и сохраняются в папку `lyrics` в данных плеера — найденный текст дальше открывается и без интернета.
- Поиск понимает приписки в названиях: «(P4D ver.)», «-Reload-», «(… Remix) -Long Mix-», «3-31» = «3/31» и т. п. Сравнивается название без приписок, а версия выбирается по совпадению приписок и длительности.
- Чужие песни с тем же названием отсеиваются: кандидат должен быть из альбома Persona/ATLUS или от известного исполнителя серии.
- Если длительность найденной записи отличается больше чем на 5 секунд, текст показывается без подсветки строк, чтобы строки не убегали от музыки.
- Ответ «текста нет» хранится 3 дня и перепроверяется сразу, как только плеер узнаёт длительность или исполнителя трека. Треки «Без названия (BGM …)» не ищутся.

## Звук

- Звук идёт через Web Audio; скачанные треки тоже отдаются через `phantom://local/<альбом>/<номер>`, чтобы их можно было измерять.
- **Выравнивание громкости** (включено по умолчанию, переключатель — «Настройки → Звук»): пока трек играет, плеер измеряет его громкость (взвешенная энергия, как в ReplayGain / EBU R128) и подгоняет к −14 LUFS — убавляет до −12 дБ, прибавляет до +6 дБ, ограничитель не даёт тихим трекам хрипеть. Неизмеренный трек сразу получает уровень своего альбома, поэтому скачков громкости между альбомами нет с первой секунды. Замеры хранятся в `phantom-player.loud.v1`.

## Интерфейс

- **Разделы:** Главная (недавние, чаще всего), Поиск (альбомы, поиск трека), Библиотека (любимые треки, сортировка, «Случайно», скачивание), Сейчас играет.
- **Нижняя панель:** прогресс трека — полоса во всю ширину по верхнему краю (клик перематывает), время по краям, кнопки по центру, громкость справа (клик по динамику выключает звук).
- **Очередь:** у каждого трека есть кнопка «в очередь» (то же меню — по правой кнопке мыши): «Играть следующим» и «В конец очереди». Трек стоит в очереди один раз — добавленный снова, он переезжает. В панели «Очередь» треки перетаскиваются мышью или с клавиатуры (фокус на полосках и стрелки вверх/вниз); показываются ближайшие 60 треков.
- **Повтор трека** — кнопка с петлёй и «1» рядом с «вперёд» или клавиша R; пока повтор включён, вместо «Далее» написано «этот же трек (повтор)».
- **Текст песни** листается колесом мыши; через 5 секунд или по кнопке «К текущей строке» он снова следует за песней. Щелчок по строке перематывает к ней.
- **Настройки** — шестерёнка справа от «Библиотеки» (в теме Persona 3 Reload — пункт меню). Тема оформления меняется сразу, без перезапуска, и запоминается.
- **Окно** без системной рамки: кнопки «свернуть / развернуть / закрыть» нарисованы в стиле темы, окно перетаскивается за верхнюю полосу, двойной щелчок разворачивает его.
- **Клавиши:** Пробел — пауза, ←/→ — перемотка на 5 с, Ctrl+←/→ — трек назад/вперёд, Ctrl+↑/↓ — громкость, R — повтор, Ctrl+F — поиск, Esc — закрыть очередь или меню. Работают и мультимедийные клавиши, и медиапанель Windows.

## Темы

### Persona 5

- Заголовки разделов — вырезанные буквы, панели «Настройки» и «Очередь» закрываются белой биркой «ЗАКРЫТЬ ▸▸».
- **Календарь на Главной** повторяет игровой: месяц и косая черта на одной наклейке, огромное число на второй, день недели на третьей (строчные гласные — как «MoNDaY» в игре), позади — плашка со значком погоды, ниже — бирка времени суток (Раннее утро / Утро / Обед / День / После уроков / Вечер / Ночь). Всё чёрно-белое, текст по-русски.
  - Подложка и край наклеек строятся SVG-фильтрами (`p5c-stk`, `p5c-wd`, `p5c-tag` в `index.html`) по форме самих букв, поэтому подходят к любой дате; длинные надписи уменьшаются автоматически.
  - Календарь рисуется в полном размере и уменьшается свойством `zoom` (0.64), чтобы текст оставался чётким; наклейки поверх плашки вынесены в отдельные слои (`will-change`), иначе Chromium при `zoom` иногда рисует плашку поверх числа.
- **Погода** настоящая: город — по интернет-адресу (GeoJS, запасной — ipwho.is; хранится сутки в `geo.json`), погода — с Open-Meteo (без ключа, раз в 30 минут). Значки: солнце / луна, облако, зонт, снежинка — с лёгкой анимацией из сдвигов и прозрачности; при включённом в Windows «уменьшении движения» анимация отключается. Без интернета — солнце днём и луна вечером.
- **Переход между разделами:** красная, белая и чёрная косые полосы влетают справа, на чёрной — лента с названием раздела, затем полосы слоями уносятся влево.

### Persona 3 Reload

Сделана по интерфейсу игры — меню паузы, экранам CONFIG, спискам и подсказкам. Шрифт Montserrat.

- Фон — море снизу: свет от поверхности, бегущие блики, пузырьки, стеклянные осколки.
- Разделы — столбик жирных наклонных голубых слов, у текущего — курсор-клин. Меню разделов видно, только пока под ним нет содержимого страницы; плеер сам меряет, где кончается свободное место.
- Заголовки — огромные серые слова на белой диагональной полосе с номером (01, 02, 03).
- Списки и очередь — как CONFIG: голубой текст, играющий трек — белая полоса с красным краем.
- «Сейчас играет» — по мотивам меню паузы: белая панель с огромным «ИГРАЕТ», трек столбиком пунктов, внизу строка «ОЧЕРЕДЬ  Далее: …».
- На Главной — дата как в игре: день/месяц, день недели, время суток (в полночь — «Тёмный час») и сколько дней до полнолуния.
- Переход между разделами — вода разливается кругами от места клика и стекает вниз.

### Metaphor: ReFantazio

Сделана по интерфейсу игры — меню паузы, спискам снаряжения, экрану поля, переходам. Шрифт Playfair Display; мазки краски сгенерированы из шума скриптом `tools/mf_textures.py` (файлы `app/src/mf/*.webp`). Стили — `app/src/mf.css`, разметка — функции `mf…` в `app.js`.

- Фон — чернила с мазками краски, у каждого раздела свои цвета (Главная — бирюза и малиновый, Поиск — малиновый и бирюза, Библиотека — фиолетовый и пурпурный).
- Меню разделов — веер антиквенных слов; выбранный раздел — на мазке кисти.
- Заголовки — огромное слово, срезанное краем окна, под ним курсивный вопрос («Что послушаем сегодня?»).
- Списки треков — плашки по мотивам списка отряда: название альбома в вырезе слева, полосы исполнителя и длительности как HP/MP, номер на месте уровня, обложка справа. Любимые треки выдвинуты вправо, играющий — красная плашка под мазком кисти. Длинные названия альбомов сокращаются (Persona 4 Dancing All Night → P4D).
- На Главной — данные как на экране поля: дата, время суток, погода с температурой, число треков и любимых.
- Переход между разделами — мазки краски и чернил проносятся справа налево; цвета плавно перетекают из цветов прежнего раздела в цвета нового.

## Телефоны

- Код интерфейса общий — `app/src`, поэтому изменения дизайна попадают во все версии сразу. Телефонные части включаются, только когда у страницы есть класс `phone` (его добавляет `mobile/scripts/build-web.mjs`); страница сама узнаёт платформу (класс `ios` или `android`).
- **Раскладка** — `mobile/web/phone.css`: внизу три раздела картинками в манере каждой темы, над ними мини-плеер с полосой прогресса, настройки — шестерёнкой на Главной. «Сейчас играет» помещается на один экран: если название занимает больше строк, обложка уменьшается ровно настолько (`fitNow` в `app.js`, `--cut` в `phone.css`). Очередь и настройки открываются на весь экран.
- **Мост к Диску, файлам, текстам и погоде** — `mobile/web/phone-api.js` (то, что на Windows делает основной процесс). Трек перед игрой скачивается в кэш (до 60 треков / 600 МБ, старые удаляются сами), а следующий в очереди — заранее, поэтому очередь продолжается и с заблокированным экраном. Треки, скачанные кнопкой СКАЧАТЬ, лежат отдельно и не удаляются.
- **Касания:** свайп по мини-плееру переключает трек, нажатие открывает «Сейчас играет», долгое нажатие на трек — меню «Играть следующим / В конец очереди», в очереди трек перетаскивается за полоски справа.
- Громкость — кнопками телефона; выравнивание громкости работает как на Windows.
- Данные на каждом устройстве свои и не синхронизируются.

### iPhone

- Проект — `mobile/ios` (Capacitor 8). Музыка рассчитана играть в фоне и с заблокированным экраном (фоновый звук в `Info.plist`, аудиосессия «воспроизведение»); экран блокировки получает трек и кнопки через Media Session.
- Установка — неподписанный `Personafy.ipa` из ветки `ios` через Sideloadly с бесплатным Apple ID. Такая подпись живёт 7 дней, потом тот же файл ставится заново поверх (данные сохраняются).
- Значок — `tools/ios_icon.py`.

### Android

- Проект — `mobile/android` (Capacitor 8), одна сборка www на оба телефона. Отличия — `mobile/web/android.js` и `mobile/android/app/src/main/java/com/tornoment/personafy/`:
  - плеер в шторке и на экране блокировки — своя служба `PlaybackService` (обложка, название, кнопки, перемотка; кнопки наушников, Bluetooth и часов). `android.js` подменяет `navigator.mediaSession`, поэтому `app.js` работает с ним так же, как на других платформах;
  - пока играет музыка, служба держит приложение на переднем плане, чтобы Android не заморозил его с выключенным экраном; после паузы — ещё 30 секунд, потом уведомление можно смахнуть;
  - если выдернуть наушники — пауза;
  - кнопка «Назад» (`MainActivity`, `backStep` в `app.js`) закрывает меню и панели, возвращает с экрана на экран, а на Главной сворачивает приложение — музыка играет дальше;
  - кнопки громкости всегда меняют громкость музыки.
- Все сборки подписаны одним ключом `mobile/android/personafy.keystore` (пароль `personafy-public`), поэтому каждая новая версия ставится поверх старой. Без этого ключа обновление не встанет — придётся удалить приложение вместе с данными. Отпечаток сертификата SHA-256: `AF:D8:84:E6:…:91:45`.
- Значки — `tools/android_icon.py`: адаптивный (фон и цилиндр отдельными слоями), одноцветный для тематических значков Android 13+ и заставка.

## Сборка и выпуск

- **Windows:** `cd app && npm install && npm run dist` → `dist/Personafy Setup.exe`. Установщик лежит одним файлом в ветке `installer`; при каждой новой версии её единственный коммит заменяется, чтобы репозиторий не разрастался.
- **iPhone:** `.github/workflows/ios.yml` — по кнопке «Run workflow» у **iPhone build** или по тегу `ios-…`. Сборка идёт на Mac от GitHub, готовый `.ipa` заменяет единственный коммит ветки `ios` (номер сборки и дата — в `build.txt`).
- **Android:** `.github/workflows/android.yml` — по кнопке «Run workflow» у **Android build** или по тегу `android-…`. Подписанный `.apk` заменяет единственный коммит ветки `android`; номер сборки служит номером версии, поэтому каждая следующая ставится поверх.
  - После сборки приложение проверяется на эмуляторе Android 14 (`mobile/scripts/android-check.mjs`): установка и запуск, музыка с Google Диска, плеер в уведомлении и на экране блокировки, кнопки наушников, перемотка, игра в фоне и с выключенным экраном, кнопка «Назад». Вторым эмулятором снимаются все три темы. Итог виден на странице запуска в Actions, снимки и журналы — во вложениях `check-app` и `check-themes`.
- Если сборка упала, журнал ошибок — во вложении `build-log` на странице запуска.
- **Проверка раскладки без телефона:** `cd mobile && npm run build:web && python3 scripts/preview.py` — снимки всех экранов трёх тем в размере iPhone (`PREVIEW_PLATFORM=android` — в размере Android-телефона).
